# RetinaTrust v0.4 — започни оттук

Приложението и числата в демонстрацията са замразеният v0.3 baseline. v0.4 добавя проверим външен протокол за DeepDRiD; външни резултати още не са изчислявани и не трябва да се цитират като налични.

## Стартиране

Windows: отвори `start_retinatrust.bat`.

Linux/macOS:

```bash
./start_retinatrust.sh
```

Приложението работи локално на `http://127.0.0.1:8765` и не записва качените изображения.

## Демонстрация за 5 минути

1. Натисни **„Зареди демонстрационно IDRiD изображение“**.
2. Пусни clean анализ и покажи отделно качество, вероятност, увереност и workflow решение.
3. Избери **„Недоекспониране“**, ниво 3, и анализирай пак.
4. Покажи, че резултатът е блокиран за повторно заснемане.
5. Натисни **„Демо: повтори с чистия вход“**, за да покажеш paired workflow-а.
6. Покажи таблицата **„Paired стрес профил върху test split“** и 95% CI.

## Основният извод

Clean AUROC е 0.720 върху 103 фиксирани official test изображения, но специфичността е само 0.359. Това е baseline за failure-mode анализ, не клинично готов модел.

При недоекспониране ниво 3 AUROC пада до 0.546, paired ΔAUROC е −0.174 (95% CI −0.287 до −0.056), а 77.7% от thresholded решенията се сменят. Quality gate се намесва във всички случаи.

Старият resize-only confound е измерен: 6.8% flips, но ΔAUROC −0.006 с интервал, който пресича нулата. Затова старият протокол е бил нечист, но resize не обяснява основния severe-underexposure ефект.

## Най-важното ограничение

Official test split-ът е повторно използван след анализ на v0.1 и не е pristine locked test set. Test labels не са използвани за обучение или избор на праг във v0.3, но е нужна външна валидация.

Прочети `docs/DEFENSE_BRIEF_BG.md` преди представяне и не представяй резултата като диагноза.

## Следващият научен run

След изтегляне на официалния DeepDRiD repository:

```bash
python scripts/verify_artifacts.py
python -m unittest discover -s tests -v
python scripts/evaluate_external.py --dataset-root "/path/to/DeepDRiD"
```

Протоколът е описан в `docs/EXTERNAL_VALIDATION_PROTOCOL_BG.md`. Не променяй модела, праговете или quality правилата след виждане на външните етикети.
